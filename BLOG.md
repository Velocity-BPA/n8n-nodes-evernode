# Automate Evernode: New n8n Community Node for Decentralized Hosting

We're excited to announce the release of n8n-nodes-evernode, a new community node that brings Evernode's decentralized hosting platform into your n8n workflows!

## What is Evernode?

Evernode is a revolutionary decentralized hosting platform built on the XRP Ledger, enabling developers to deploy HotPocket smart contracts across a distributed network of hosts. With its native EVR token economy, Evernode creates a sustainable ecosystem for decentralized application hosting.

## The Problem We're Solving

As blockchain and decentralized technologies mature, automation becomes critical for managing smart contracts, monitoring hosting infrastructure, and integrating Web3 services with traditional business systems. Until now, connecting Evernode to your automation workflows required custom development and complex API integrations.

The n8n-nodes-evernode changes that entirely.

## Key Features

This community node enables you to:

- **Manage HotPocket smart contracts** directly from your n8n workflows
- **Monitor Evernode hosting infrastructure** and respond to events automatically
- **Integrate EVR token operations** with payment systems and business logic
- **Automate deployment workflows** for decentralized applications
- **Connect Web3 and Web2** seamlessly within a single automation platform

Whether you're building monitoring dashboards, automating smart contract deployments, or creating complex integration workflows between Evernode and your existing systems, this node provides the building blocks you need.

## Getting Started

Installing the Evernode node is simple. In your n8n instance, run:


npm install n8n-nodes-evernode


After installation, restart n8n and you'll find the Evernode node available in your node palette, ready to integrate into your workflows.
